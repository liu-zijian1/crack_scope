# 双目标定与深度换算

双目深度依赖相机内参、左右相机相对姿态和基线距离。仓库中的 `calibration/stereo_calibration.json` 与 `.npz` 是本项目一台相机的样例；不同型号、焦距、分辨率或相机固定状态都应重新标定。

## 标定板和采集

示例配置使用内角点为 8×6、方格边长 25 mm 的棋盘格，每目输入分辨率为 1280×960。打印后用尺子实测格长；纸张缩放会直接造成距离比例误差。将标定板放在画面不同位置和角度，采集多组同步左右图像，避免所有样本都集中在画面中央。

项目的现有标定结果使用 15 组左右图像。日志中 RMS 重投影误差只能用于检查拟合质量，不等于最终毫米测量误差。要复现标定，需要运行 OpenCV 的棋盘格角点检测、单目标定、双目标定和 `stereoRectify`，将左右投影矩阵、畸变参数和校正映射保存为 `.npz`。更换相机或镜头后不要复用旧文件。

把左右目图像分别放入目录，并确保同一对图像使用相同文件名。运行仓库脚本：

```bash
python scripts/calibrate_stereo.py \
  --left data/calibration/left \
  --right data/calibration/right \
  --corners 8 6 \
  --square-mm 25 \
  --output calibration/stereo_calibration.npz
```

脚本至少需要 10 组能同时检测到棋盘格的同步左右图像；建议从不同距离、位置和角度采集更多图像。它会输出 OpenCV 标定参数 `.npz` 和可读摘要 `.json`。

部署时设置：

```text
CRACKSCOPE_CALIB=/absolute/path/to/stereo_calibration.npz
```

仓库样例的默认路径为 `calibration/stereo_calibration.npz`。代码按标定结果校正左右图像，再由视差估计深度。

## 深度和裂缝宽度

理想校正双目模型中，深度近似为：

```text
Z = fx × B / d
```

其中 `fx` 是水平方向焦距（像素），`B` 是左右相机基线，`d` 是对应点视差（像素）。裂缝宽度再由分割区域的像素宽度和该处深度换算为毫米。深度会受纹理、反光、遮挡、相机同步、标定和分割质量影响；请用已知尺寸的标定物验证自己的装置，不要把示例误差指标当成精度保证。

## 校准验证

1. 固定相机和焦距，确认左右相机图像均能稳定读取。
2. 检查校正后同一平面上的角点是否大致落在同一水平线上。
3. 用若干已知距离和尺寸的目标比较测量结果，记录误差和测试条件。
4. 若系统报告无有效深度，检查标定文件路径、图像分辨率、左右图顺序和视差图。
